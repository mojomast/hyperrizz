# Broadcast kit provenance

The CRT/VHS shader structure, stateless spatial-echo technique, four-step sprite
animation, manifest-based accessory placement and broadcast-clock conventions are
adapted from **Hermagotchi Television**, source revision
`6b223aa8cab2999bb19ebc06e99f603b03d0ca3d`, under its MIT code license.

The original copyright notice is retained in `LICENSE`. Hyperrizz generalizes the
fixed 1080p shader dimensions, exposes explicit frame/rate controls, adds an actual
clean bypass and power-off collapse, validates rig units, and makes the sequence
cache independently reusable. Cross-GPU floating-point identity is not promised.

No original game artwork, NPC portraits, catalog assets, branded wordmark, fonts or
production recordings are included. The advanced lab generates its own clearly
labelled synthetic sprite fixtures, FFmpeg test signal and original sound cues.
These demonstrate compositing techniques, not game behavior or a live app.
